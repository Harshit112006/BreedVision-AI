# Languages

The web app can be used in **English, हिन्दी (Hindi), मराठी (Marathi), தமிழ் (Tamil)
and తెలుగు (Telugu)**. A language picker sits in the header (and in the mobile
menu). The choice is remembered on the device; on a first visit the browser's
language is used if it is one of these.

## What is translated

The path a field user actually takes: navigation, footer, home page, the identify
page and the whole identify flow (photo guidance, progress, result, confidence
labels, save and location messages), duplicate-photo notices, the demonstration-data
notice and the "where the model looked" panel. Dates follow the chosen language.

## What is not translated yet

These stay in English until their strings are added:

- Breed library and breed detail pages, History and saved-record pages, Prices and
  the sale log, Account, and the developer "foundation" page.
- Browser tab titles and page descriptions (they are fixed on the server).
- Error messages produced by the service layer (for example "image too large"),
  location error text, and the explanation text returned by the API
  (the heat-map summary and limits).
- Breed names and breed facts. Breed names are proper nouns and are shown as
  stored.

Nothing breaks when a string is missing: it falls back to the English text.

## Quality: needs review by native speakers

These translations were written by Claude, not by a translator, and **no native
speaker has reviewed them**. Hindi is the most likely to be right; Marathi, Tamil
and Telugu should be checked before any real field use, especially the lines that
carry caution: the confidence-band labels, the duplicate-photo caveat and the
heat-map note. Livestock terms may also differ by region.

## Adding or fixing a language

All text lives in `web/src/i18n/messages/`. `en.ts` is the source; each other file
is a partial copy. To add a language, copy `hi.ts`, translate the values, then add
it to `LOCALES` and `CATALOGUES` in `web/src/i18n/index.tsx`.
`web/tests/i18n.test.mts` checks that every key exists in English, no value is
empty, and `{placeholders}` are kept.

Fonts: Inter has no Devanagari, Tamil or Telugu letters, so Noto Sans for those
scripts is loaded. The browser downloads one only when a page uses its script.
